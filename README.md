# 📚 Guías y Herramientas

Guías de estudio prácticas en español, pensadas para aprender **haciendo**.

## Guías disponibles

| Guía | Descripción |
|---|---|
| [🐧 Expresiones regulares y `grep` (LPIC-1)](guias/regex-grep-lpic1/README.md) | De cero a *master*: **630 ejercicios** con salida real verificada, un laboratorio de prácticas que se monta con un script y preguntas tipo test de LPIC-1. Explicado paso a paso, desde "qué es una terminal" hasta `grep -P`, `sed`, `find -regex` y tuberías/redirecciones. |
| [🔐 Permisos en Linux (LPIC-1)](guias/permisos-linux-lpic1/README.md) | De cero a *master*: `ls -l` leído de un vistazo, `chmod` (letras y octal), `umask`, `chown`, **SUID/SGID/sticky**, conversión octal ⇄ binario ⇄ letras, diagnóstico de *Permission denied* y un mini-examen. **188 ejercicios** con salida real verificada (probando **como otros usuarios**), un laboratorio con script, dos herramientas de línea de comandos (`permisos`, `diagnostica`), una calculadora de `chmod` y un entrenador de conversión rápida en HTML. |

## Cómo empezar

```bash
git clone https://github.com/TheBillBull/Guias-y-Herramientas.git
cd Guias-y-Herramientas/guias/regex-grep-lpic1      # o guias/permisos-linux-lpic1
less README.md
```
